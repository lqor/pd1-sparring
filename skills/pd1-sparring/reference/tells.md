# Exam tells (sample)

The full playbook of wording patterns is part of the full pack. Three to start with:

- **The simplest tool that fully meets the requirement wins.** Formula, roll-up summary and validation rule before Flow, Flow before Apex.
- **"Partial success" or "valid records should still save"** means a Database method with allOrNone set to false. The DML keyword is all-or-nothing.
- **Sharing keywords decide which records; USER_MODE and stripInaccessible decide which fields.** A field-visibility bug is never fixed by `with sharing`.

Every question in the sample also carries its own tell.
