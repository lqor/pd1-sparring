# PD1 Sparring Partner — free sample

The full coach with 12 questions (3 per exam section) and one hands-on kata, so you can see how sparring feels before you buy.

## Install

- **Claude Code**: copy this `pd1-sparring` folder into `~/.claude/skills/`, start a new session.
- **Claude desktop or web app**: Settings → Capabilities → Skills → Upload skill, choose the zip. Code execution must be on.
- **Codex CLI and other agents with skills**: copy the folder into the agent's skills directory.
- **Any other agent that reads files and runs Python**: say `Read pd1-sparring/SKILL.md and follow it.`

Then say: `let's spar for PD1`. Python 3.8 or newer is needed for the progress engine.
